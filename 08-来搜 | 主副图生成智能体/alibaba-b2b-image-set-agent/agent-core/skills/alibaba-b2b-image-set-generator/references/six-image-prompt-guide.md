## 1. 设计原则

- 固定输出 6 张独立 `1:1` 方图，推荐 `1000×1000`；不得生成六宫格、拼图、边框或 contact sheet。
- 第 1 张默认为高信息密度封面主视觉；只有用户明确要平台合规纯白底图时才切换，第 2-6 张继续按产品、买家、素材和证据动态选择。
- 每张图只解决一个核心采购主题，但必须用 3-6 个短卖点、细节、应用或信任模块共同支撑。
- 每个卖点必须同时具备：产品依据、买家价值、视觉表达。
- 有真实产品图时，所有产品相关输出都用 `image_edit` 并复用同一主产品参考图。
- 没有真实产品图时，默认只交付方案和 Prompt；用户接受概念稿后，只用 `image_generate` 生成第 1 张概念主参考，其余 5 张改用 `image_edit`。
- 白底主图必须基于真实产品照片；概念图不能标为可直接上架。

### 1.1 丰富度合同

除明确要求的纯白底图外，每张成品至少具备下列 5 类中的 4 类：

1. 主张层：强标题和一行副标题，一眼说清本张采购主题。
2. 主体层：产品或核心部件占 40%-55% 画面，明显大于其他模块。
3. 核心卖点层：2-3 个图标 + 短标题 + 极短证据文案。
4. 可视证明层：2-3 个材料、应用、部件、局部特写或结果卡片。
5. 采购信任层：3-4 个底部短项，用于已证实的质量、操作、包装、定制或服务信息。

让内容密而不乱：固定上、中、下三段网格，四周保留约 6%-8% 安全边距，卡片对齐，图标风格一致，字号不低到无法在移动端阅读。丰富度来自视觉证据和模块层级，不是把长段说明书塞进图片。

### 1.2 不同图位的丰富度变体

| 图位主题 | 主体 | 上层模块 | 下层模块 | 底部条 |
|---|---|---|---|---|
| 封面主视觉 | 完整产品 | 3 个最强卖点 | 3 个应用/材料卡 | 3-4 个信任点 |
| 结构细节 | 产品 + 核心部件 | 2-3 个机制卖点 | 3 个局部放大卡 | 材质/维护/操作点 |
| 应用兼容 | 产品使用场景 | 2 个场景收益 | 3 个应用或材料卡 | 适配/操作/结果点 |
| 参数选型 | 产品 + 尺寸/接口 | 2 个选型结论 | 参数网格或规格卡 | 安装/控制/维护点 |
| 定制交付 | 产品 + 真实定制/包装素材 | 2-3 个定制选项 | 颜色/包装/标识卡 | 质检/打样/交付点 |

## 2. 卖点链与筛选

### 2.1 卖点链

每个候选卖点填写以下字段：

| 字段 | 要回答的问题 |
|---|---|
| 产品特征/机制 | 产品哪个部件、材料、结构、功能或能力产生价值？ |
| 买家问题 | 采购商担心什么，或要完成什么任务？ |
| 买家收益 | 节省什么、改善什么、降低什么风险？ |
| 事实依据 | 来自用户确认、图片可见、参数表还是授权素材？ |
| 视觉表达 | 用特写、标注、使用场景、结果、对比还是流程证据表达？ |
| 英文文案 | 能否用一个短标题和 2-4 个短标签讲清？ |

### 2.2 优先级评分

对候选卖点按四项各评 `高/中/低`：

1. 产品相关性：是否只有当前产品或该细分类目才成立。
2. 买家重要性：是否直接影响选型、使用、风险或采购决策。
3. 证据强度：是否有用户确认、可见结构、真实参数或素材支持。
4. 视觉表现力：是否能通过画面证明，而不是只能写一句口号。

优先采用四项中至少三项为 `高` 的候选。证据为 `低` 的候选只能标为待确认，不进入最终图片。

### 2.3 泛卖点改写

| 弱表达 | 改写方向 |
|---|---|
| High Quality | 指出支撑质量的材料、结构、工艺、检测或可见细节 |
| Durable | 指出承力结构、表面处理、连接件、耐用场景或已确认测试 |
| High Efficiency | 指出操作步骤、处理能力、自动化机制或已确认速度参数 |
| Easy to Use | 指出控制方式、安装结构、维护入口或减少的操作步骤 |
| Wide Application | 列出已确认的材料、场景、行业或适配对象 |
| Professional Service | 改为有证据的定制、打样、包装、质检或售后范围 |

判断标准：如果换成另一个无关产品仍然成立，就继续具体化。

## 3. 五类设计方向

| 方向 | 重点 | 常用视觉语言 | 适合回答 |
|---|---|---|---|
| 核心功能型 | 产品完成的关键任务和结果 | 主体大图、动作瞬间、输入/输出、结果特写 | 它能帮我做什么？ |
| 结构细节型 | 支撑性能的部件、材料和工艺 | 局部放大、指示线、剖面、材质特写 | 为什么能做到？ |
| 参数证据型 | 影响选型的已确认数据 | 参数卡、尺寸线、规格层级、范围对比 | 是否满足我的规格？ |
| 应用结果型 | 场景、材料、对象和最终效果 | 真实环境、使用动作、材料样本、结果陈列 | 适合我的业务吗？ |
| 供应信任型 | 定制、质检、包装、工厂和交付 | 真实素材分区、流程节点、包装细节 | 下单和长期合作是否可靠？ |

一套图通常选择 2-4 个方向。工业品常用“核心功能 + 结构细节 + 应用结果 + 参数证据”；消费品常用“核心功能 + 场景 + 细节 + 定制”；只有真实供应证据时才加入供应信任型。

## 4. 动态六图选位

### 4.1 固定买家旅程

```text
看清产品 → 理解价值 → 相信依据 → 想象使用 → 完成选型 → 降低采购风险
```

### 4.2 选位规则

| 图 | 必须完成的任务 | 可选角色 |
|---|---|---|
| 1 | 快速理解产品与主要价值 | 高信息密度封面主视觉；用户明确要求时改为纯白底主图 |
| 2 | 建立最强购买理由 | 核心功能、核心结果、旗舰卖点 |
| 3 | 证明“为什么” | 结构、材质、工艺、核心部件、细节 |
| 4 | 建立使用想象 | 场景、材料兼容、行业应用、人物使用 |
| 5 | 支持专业选型 | 参数、性能、尺寸、控制、安装、安全、维护 |
| 6 | 消除剩余风险 | 定制、包装、质检、工厂、交付、人物比例，或第二个强证据卖点 |

第 2-6 张可以重排。只要每张回答不同问题，并且六张共同覆盖买家旅程即可。

### 4.3 替换规则

- 无真实工厂或流程素材：用结构、应用、包装实物、安装或维护卖点替代。
- 产品不适合人物：用尺寸、部件、加工结果或操作界面替代。
- 无已确认参数：用可见结构、使用场景或已确认功能替代。
- 产品本身卖点少：围绕不同买家问题展开，而不是把一个卖点重复六次。
- 产品结构复杂：一张展示整机结构，一张展示关键部件，一张展示产出结果，避免每张都是整机海报。

### 4.4 用户可选维度

先由 Agent 基于产品推荐六维度，再允许用户替换任意图位。常见替换项包括：模特/人物使用、人体比例、颜色定制、Logo 定制、包装、配件套装、安装步骤、维护、工厂、质检、交付、场景或结果对比。

模特维度不只是“在旁边放一个人”，必须服务于下列至少一项：展示穿戴效果、真实使用姿势、人体尺度、操作位置、目标市场场景或使用后的可见结果。产品仍是主体，人物不能遮挡关键结构或导致产品比例失真。

## 5. 行业适配示例

### 5.1 机械、工具、工业品

推荐选位：

1. 白底整机。
2. 核心加工/作业结果。
3. 关键部件和结构证明。
4. 材料或行业应用。
5. 已确认参数、控制、安装、安全或维护。
6. 有证据的质检、包装、定制，或第二个专业证明。

石材水刀示例：

| 产品依据 | 买家收益 | 视觉表达 | 可用短文案 |
|---|---|---|---|
| 冷态水流切割机制 | 避免热影响造成的边缘问题 | 水刀头工作特写 + 石材切边 | `NO HEAT-AFFECTED ZONE` |
| 龙门与大幅面工作台可见 | 支撑大尺寸石材加工表达 | 整机俯视 + 台面尺寸关系，不写未知数值 | `BUILT FOR LARGE STONE SLABS` |
| 切割头与运动结构可见 | 适合复杂轮廓加工的候选方向 | 切割路径线 + 拼花结果；性能未确认时标待确认 | `INTRICATE CONTOUR CUTTING` |
| 用户确认适用大理石、花岗岩、瓷砖 | 降低材料适配风险 | 三种真实材料样本与加工结果 | `MULTI-MATERIAL STONE PROCESSING` |

不得仅凭图片写 `±0.1 mm`、水压、速度、连续运行时间或认证。

### 5.2 服装、鞋帽、家纺

推荐选位：

1. 白底完整款式。
2. 上身/使用场景。
3. 面料纹理、缝线、拉链或边角。
4. 版型、活动性或场景收益。
5. 已确认尺码、面料、克重或功能。
6. 已确认颜色、Logo、包装或 OEM 选项。

保持真实版型、颜色和图案；不虚构材质比例、功能测试和品牌吊牌。

### 5.3 包装、美妆、礼品

推荐选位：

1. 白底包装完整形态。
2. 货架、礼盒、旅行装或使用场景。
3. 瓶口、泵头、盖子、印刷或内托细节。
4. 容量、密封、操作或组合方式。
5. 已确认尺寸、容量、材质或兼容范围。
6. 有证据的颜色、Logo、表面工艺、内托或包装定制。

不生成药效、检测报告、知名品牌包装或未确认的防漏性能。

### 5.4 电子、电器、灯具

推荐选位：

1. 白底产品与真实配件。
2. 核心功能或照明效果。
3. 接口、按钮、散热、安装结构。
4. 家庭、商业、户外或工程场景。
5. 已确认功率、电压、续航、尺寸、IP 等级或控制方式。
6. 安装、包装、配件、定制或维护。

未确认的规格、软件功能和认证不得进入图片。

### 5.5 家具、建材、家居用品

推荐选位：

1. 白底完整产品。
2. 酒店、公寓、办公室、工程或家装场景。
3. 纹理、连接结构、边角或安装细节。
4. 尺寸比例、收纳、承载或空间使用。
5. 已确认材质、尺寸、表面处理或组合方式。
6. 已确认颜色、规格、包装、安装或项目供应能力。

不虚构项目案例、防火等级、环保等级或承重数值。

## 6. 共享视觉系统

先从产品本身提取视觉语言：

- 主色：优先来自产品、品牌和材质，不默认套蓝色科技风。
- 强调色：用于指示线、数字、图标和关键标签，整套固定一种。
- 背景：白底、真实场景、深色技术背景或温暖生活方式背景要与行业和卖点匹配。
- 字体：工业品偏清晰硬朗，消费品偏精致，家居偏克制，不混用多套字体气质。
- 光线：固定色温、阴影方向和产品质感。
- 标注：统一线宽、圆角、图标、边距和信息层级。

增强视觉冲击力与商业完成度的方法：

- 让产品或核心部件成为唯一视觉焦点。
- 用大场景与微距细节形成节奏变化。
- 用真实结果、材料样本、指示线和局部放大证明卖点。
- 用留白和尺度对比建立高级感，不靠过量光效、粒子和装饰。
- 一张图只放一个主标题，但可用多个短标签和卡片建立丰富层级；不要把说明书塞进图片。
- 第 1 张通过质检后成为风格母版；后续图片沿用其配色、标题层级、卡片样式、图标线条、边距和光线。

## 7. `image_edit` Prompt 模板

```text
Create image <N> of 6 for an Alibaba.com B2B product image set.

Product identity: <confirmed product>.
Image role: <dynamic role>.
Buyer question: <one procurement question>.
Primary selling point chain:
- Product feature or mechanism: <confirmed or image-visible fact>.
- Buyer benefit: <specific business or use benefit>.
- Evidence shown in the image: <detail, material, parameter, scene, result, or supplied reference>.

Art direction: <industry-fit palette, lighting, typography, composition, visual hierarchy>.
Composition: <camera angle, product scale and placement, background, callouts, close-ups, whitespace>.
Commercial density contract:
- Strong headline zone plus one concise subheadline.
- Two or three aligned icon-led benefit modules.
- Dominant product hero occupying about 40-55% of the canvas.
- Two or three visual evidence cards showing applications, materials, components, close-ups or results.
- Bottom procurement-confidence strip with three or four evidence-backed short items.
- Use a disciplined top-middle-bottom grid, consistent card geometry and icon style; dense and polished, never empty or sparse.
Visible English text:
- Headline: <one short product-specific claim>.
- Supporting labels: <short evidence-backed labels for the selected modules; no paragraph text>.

Shared visual system: <fixed palette, color temperature, label and spacing system>.
Output: one standalone 1:1 square image, not a grid, collage, border, storyboard or contact sheet.

Keep the product exactly unchanged — preserve geometry, color, material, texture, labels, logo placement, proportions, and recognizable components.
Only change: <allowed background, layout, callouts, model or scene>.
Do not redraw, simplify, replace, or invent any product detail.
No unsupported number, certification, factory, customer, capacity, MOQ, lead time or performance claim.
Do not deliver a sparse layout with only one headline, one isolated product and a mostly empty background.
```

若用户明确要求改色，产品颜色是唯一允许改变项，其他结构和材质保持不变。

## 8. `ask_user` 问法

默认最多主动询问一次卖点偏好：

```text
要不要补充或指定这套图最想强调的卖点？
- 直接采用推荐卖点
- 我补充 1-3 个真实卖点或参数
- 优先某类买家或应用场景
- 只使用图片可见和资料已证实的安全卖点
```

以下情况不主动问卖点：

- 用户已经提供清晰的卖点、参数和目标场景。
- 用户说“直接生成、生图、按推荐方案做”。
- 用户只要求审阅或修改现有某一张图。

以下情况可以追加一个阻断性问题：

- 产品身份或 SKU 不清楚。
- 多张图片中主参考图不清楚。
- 用户要求的参数、认证、工厂或定制卖点没有事实依据。
- 概念路线和真实商品路线尚未确认。
