# 展会全流程方法

本参考从本地展会操作资料提炼流程，不复制其中公司、客户、金额或话术。

## 展前

- 确定目标、客户分层、人员角色、展位表达、样品、物料、预算和培训。
- 对重点客户准备一页背景、会面目标、必问问题、可展示证据和禁承诺项。
- 现场资料应能快速找到，不依赖临时联网。

## 展中

- 主谈、记录、展示和决策角色分开。
- 记录客户业务模式、产品需求、数量/时间线索、决策流程、顾虑、承诺和下一步。
- 每天结束复盘新增线索、重点客户、资料缺口和次日动作。

## 展后

- 先确认会谈共识，再发送与需求相关的资料。
- 线索按价值、匹配、时机和证据分级。
- 每个动作有负责人、截止时间、交付物和复查节点。
