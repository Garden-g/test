# 展会营销策划

把参展从“布置展位”变成一条客户转化链：展前确定目标客户并邀约，展中识别需求和记录承诺，展后按优先级推进。

## 工具

- `ask_user`：确认展会名称/日期/地点、产品、目标客户、名单、预算、展位、团队、样品和业务目标。
- `list`、`read`：读取参展资料、客户名单、产品目录、报价、证书、历史展会和人员信息。
- `web_search`、`web_fetch`：核对当前展会官网、参展规则、交通/文化/节日等公开信息。
- Browser：公开官网依赖脚本渲染时使用；不替用户登录报名。
- `write`、`bash`、`process`、`present_files`：生成执行表格。

## 工作流

1. 定目标：品牌、重点客户会面、新客户、老客户激活、代理招募、样品/订单或市场调研；每项写量化口径和负责人。
2. 客户分层：已预约重点客户、待邀约目标客户、现场新线索、同行/合作伙伴；不同类型使用不同接待目标。
3. 展前准备：人员分工、培训演练、展位信息、样品、报价、证书、产品资料、记录工具、礼品和应急方案。
4. 展中接待：快速分辨角色与需求，围绕应用、采购、决策、预算、时间、风险提问；记录事实、承诺和下一动作。
5. 每日复盘：线索分级、遗漏信息、明日预约、样品/报价需求、竞争观察和团队改进。
6. 展后跟进：当天确认会谈要点；按优先级安排资料、样品、报价、会议和拜访；设置停止/降级条件。

方法清单见 `references/method.md`。

## 表格交付

生成 `展会营销作战表_<展会>_<日期>.xlsx`：

| Sheet | 内容 |
|---|---|
| `目标与预算` | 业务目标、指标、预算、负责人和审批。 |
| `客户邀约` | 客户、分层、会面目标、邀约状态和下一步。 |
| `人员分工` | 角色、班次、主谈/记录/展示/决策和应急职责。 |
| `样品与物料` | 样品、资料、证书、设备、数量、状态和负责人。 |
| `现场接待` | 客户信息、需求、采购线索、承诺、证据和下一节点。 |
| `展后跟进` | 优先级、动作、负责人、截止时间和复查结果。 |
| `复盘与缺口` | 每日复盘、市场发现、问题、成本和补数动作。 |

```bash
python3 scripts/build_workbook.py --input trade_show.json \
  --output outputs/展会营销作战表_<展会>_<日期>.xlsx \
  --expected-sheets '目标与预算,客户邀约,人员分工,样品与物料,现场接待,展后跟进,复盘与缺口'
```

## 边界

- 不编造展会日期、规则、客户到场、预算、报价、证书或成交。
- 不自动报名、订票、订酒店、发送邀约、签合同或收定金。
- 食品、礼品、拍照录音、隐私和营销联系应按展会及当地规则复核。
- 所有价格、折扣、代理权、样品和交付承诺均需用户确认。
