# 海外地推拜访

把海外拜访设计成“目标客户优先、路线可执行、每次会面有明确结果、当天能跟进”的销售行动，不把行程排满当作成功。

## 工具

- `ask_user`：确认国家/城市、日期、客户名单、会面状态、业务目标、预算、团队、交通、安全和不可变时间。
- `list`、`read`：读取客户资料、沟通记录、报价、产品、样品、证书、行程和内部审批。
- `web_search`、`web_fetch`：核对客户官网、公开地址、市场渠道、目的地规则、节日和安全线索。
- Browser：公开网页依赖脚本渲染时使用；不替用户预约或下单。
- `write`、`bash`、`process`、`present_files`：生成拜访表格。

## 工作流

1. 客户分层：重点合作深化、现有大客户维护、潜在客户验证、渠道/门店调研。每类设不同会面目标。
2. 对每个客户建立一页背景：公开事实、历史沟通、产品匹配、关键人员、会面目标、必问问题、展示证据和禁承诺项。
3. 路线先按已确认会面和地理簇排列，再留交通、延误、复盘和临时客户缓冲；未确认约见不能写成确定行程。
4. 准备公司/产品资料、样品、认证、报价、合作方案、礼品和记录工具；按客户需要选择，不携带全部资料。
5. 会面中记录事实、需求、采购/项目时间、决策流程、顾虑、承诺和下一节点；现场观察只写可见事实。
6. 每天结束做客户分级、问题补齐、路线调整和当天邮件摘要；重要客户设置二次拜访条件。

详细方法见 `references/method.md`。

## 表格交付

生成 `海外拜访作战表_<国家>_<日期>.xlsx`：

| Sheet | 内容 |
|---|---|
| `行程总览` | 城市、日期、确认状态、交通缓冲、成本和风险。 |
| `客户优先级` | 客户类型、价值、匹配、会面目标、证据和状态。 |
| `客户作战卡` | 背景、议题、问题、展示材料、禁承诺和收口。 |
| `物料与准备` | 样品、资料、证书、礼品、设备、责任人和状态。 |
| `拜访记录` | 事实、需求、承诺、分歧、照片/文件授权和下一步。 |
| `会后动作` | 动作、负责人、截止时间、交付物和复查点。 |
| `成本与风险` | 预算、实际、交通、安全、合规和应急预案。 |

```bash
python3 scripts/build_workbook.py --input field_sales.json \
  --output outputs/海外拜访作战表_<国家>_<日期>.xlsx \
  --expected-sheets '行程总览,客户优先级,客户作战卡,物料与准备,拜访记录,会后动作,成本与风险'
```

## 边界

- 当前签证、入境、健康、安全、交通和当地法律必须查权威来源并由用户复核。
- 不自动订票、订酒店、预约客户、发送消息、导航或支付。
- 不编造客户地址、会面确认、关键人、预算、采购量或市场结论。
- 合同、付款、代理、报价和拍摄授权必须由用户确认。
