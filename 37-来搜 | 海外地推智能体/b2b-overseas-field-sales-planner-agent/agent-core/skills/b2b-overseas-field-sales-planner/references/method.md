# 海外拜访方法

本参考从本地海外拜访资料提炼流程，不复制其中客户、案例、金额或话术。

## 客户类型与目标

- 合作深化：理解客户前端渠道、产品线与下一年度计划。
- 重点维护：展示重视、解决问题、共创新项目。
- 潜在客户：验证公司、需求、采购流程和真实合作条件。
- 市场走访：观察门店、价格带、陈列、服务和本地竞争，仅记录可见事实。

## 路线原则

先锁定关键会面，再按地理簇组织；为交通、迟到、会议延长、当天复盘和临时变化留缓冲。未经客户确认的时间必须标“待确认”。

## 会后闭环

当天复述会谈结论和双方动作；对质量、付款、认证、售后和合同问题指定内部责任人；下次联系必须带着已完成的交付物。
