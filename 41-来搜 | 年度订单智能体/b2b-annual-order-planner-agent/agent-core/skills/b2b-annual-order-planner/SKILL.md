# 年度订单方案

年度方案的核心是用可承受的权益换取更稳定的采购预测、订单节奏、现金流或合作投入，而不是简单打折。

## 工具

- `ask_user`：确认客户历史订单、预计需求、目标增长、毛利、现金流、产能、交期、付款、库存、可给权益和审批人。
- `list`、`read`：读取订单记录、报价、成本、客户计划、营销案例和现有合同。
- `web_search`、`web_fetch`：按需核对客户公开计划、行业季节、国家节日或市场节点。
- Browser：公开网页必须脚本渲染时使用。
- `write`、`bash`、`process`、`present_files`：生成并交付年度方案表格。

## 前置条件

没有历史采购、毛利底线、产能和现金流边界时，只能输出“待测算方案框架”，不能给最终返点、折扣或授信。用户提供的金额和比例必须标币种、含税/不含税、运费和适用订单范围。

## 工作流

1. 建立客户基线：过去 12 个月订单额、频次、SKU、季节、付款、交期、异常和复购节奏。
2. 用 `ask_user` 确认企业希望换取的结果：总额增长、预测锁定、定金提前、SKU 集中、新品测试、联合营销或区域投入。
3. 设计基础/增长/战略三档。每档都写目标、订单节奏、客户权益、我方成本、触发条件、失效条件和审批要求。
4. 权益可以来自价格、返利、样品、备品、设计、仓储、交付、市场资料和管理协同，但每一项都要量化企业成本和履约责任。
5. 对优惠叠加、提前定金、返利结算、未完成目标、退货、汇率、运费、库存、独家和争议处理做压力检查。
6. 准备谈判顺序：先确认客户计划与价值，再展示档位；不从最低价格开始。

本地知识材料提炼的方法见 `references/method.md`。其中历史倍数与返点区间仅作为内部启发，不能替代当前客户测算。

## 表格交付

生成 `年度订单方案_<客户>_<年度>.xlsx`：

| Sheet | 内容 |
|---|---|
| `客户基线` | 历史订单、节奏、SKU、付款、异常和数据缺口。 |
| `三档方案` | 年度目标、节奏、权益、触发条件和失效条件。 |
| `权益成本` | 权益价值、企业成本、毛利影响、现金流和审批。 |
| `履约与风险` | 产能、库存、交期、付款、汇率、合规和退出机制。 |
| `谈判路线` | 问题、价值证明、交换条件、底线和下一步。 |
| `待确认事项` | 财务、法务、供应链、管理层和客户待确认项。 |

```bash
python3 scripts/build_workbook.py --input annual_order.json \
  --output outputs/年度订单方案_<客户>_<年度>.xlsx \
  --expected-sheets '客户基线,三档方案,权益成本,履约与风险,谈判路线,待确认事项'
```

## 边界

- 不把知识库里的示例金额、倍数、比例或礼品直接套给客户。
- 不编造采购预测、利润、成本、产能、库存、审批或客户承诺。
- 不自动发送方案、修改报价、创建订单、调整授信或签署合同。
- 合同、税务、返点和独家条款必须由财务/法务审核；本 Skill 不提供法律意见。
