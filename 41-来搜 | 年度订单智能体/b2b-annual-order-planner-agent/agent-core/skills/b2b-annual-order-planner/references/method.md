# 年度订单设计方法

本方法只保留知识材料中的抽象结构，不复制具体案例或金额。

## 三档设计

- 基础档：客户容易进入，重点换取更稳定的订单节奏。
- 增长档：要求明确增量或提前计划，权益和管理支持同步增加。
- 战略档：要求更强预测、付款、市场或渠道承诺，才配置高成本权益。

档位之间的增量应足以让客户理解升级价值，但具体倍数必须由历史订单、毛利和产能测算。

## 权益类型

价格/返利、样品/备品、定制/设计、仓储/交付、市场资料、培训、例会、管理层协同。任何权益都要同时写客户价值、企业成本、使用条件和失效条件。

## 压力检查

检查最坏情形：客户只拿优惠不完成目标、权益重复叠加、汇率变化、运费上涨、定金不足、需求集中导致产能挤压、未售库存、质量索赔和合作提前终止。
