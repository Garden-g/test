# TikTok 公开线索方法

## 查询组合

- 产品词 + distributor/wholesale/store + 国家或语言
- 应用场景 + installer/retailer/brand + 国家
- 产品词 + TikTok account/hashtag/profile
- 账号名或简介域名 + company/about/contact

## 线索类型

- 销售开发：公司、品牌、门店、进口商、经销商或服务商账号。
- 内容合作：行业创作者、测评、教程或项目展示账号。
- 待核验：无法连接到公司主体、只有聚合转载或信息过少。

## 证据规则

账号主页、代表内容、官网、公开联系页和公司信息分别记录。不能用同一个搜索摘要充当多条独立证据。
