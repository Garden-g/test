# YouTube 公开线索方法

## 查询组合

- 产品词 + distributor/importer/wholesaler + 国家
- 应用场景 + buyer/retailer/installer + 国家
- 产品评测/安装/门店/展会视频 + 品牌或公司
- site:youtube.com + 产品词 + 国家/语言词

## 强证据

- 频道 About 或视频简介明确指向公司官网。
- 官网说明其业务模式、产品范围和服务地区。
- 视频持续展示相关产品、门店、仓库、项目或渠道活动。
- 公开业务邮箱/表单可回到同一公司域名。

## 弱证据

只有标签、一次性视频、聚合转载、纯个人兴趣内容或无法对应公司的账号。弱证据不能单独支持“潜在买家”结论。
