# 商品矩阵缺口

## 触发词

产品矩阵缺口、类目覆盖不足、补品方向。

## 先读哪些证据

- `data_advisor_shop_product`：看类目、商品层级和效果分布。
- `data_advisor_to_product`：分析访客还访问商品和机会方向。
- `list_products / list_products_by_name`：盘点现有商品覆盖。
- `query_attribute_info` + `query_attribute_options_info`：确认类目属性定义、规格维度和系统选项。
- `data_advisor_shop_region`：按目标市场判断价格带或品类缺口。

## 判断方式

没有行业机会数据时只写假设，不能写确定爆品。

校准规则：没有可迁移数字阈值时，只做定性分级，并写明需按行业、店铺历史或用户确认口径校准。

## 执行步骤

1. 先确定要看类目、价格带、规格、场景还是国家市场缺口。
2. 用现有商品和访客流向识别已覆盖、重复和缺失方向。
3. 把缺口拆成可优化现有商品和需要新增商品两类。
4. 输出补品方向、验证指标和素材/类目准备要求。
5. 不直接创建商品；发品转新品或相似发品流程。

## 输出重点

缺口机会、补品优先级、验证方式。

## 常见误判

- 证据不足时给确定结论。
- 把建议动作写成已执行动作。
- 没有区分用户确认前后的边界。
- 把本子场景扩展成完整店铺报告或其他专门流程的交付物。
