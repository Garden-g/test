# 商品组合复盘

## 触发词

商品组合、产品矩阵、橱窗复盘、价格带。

## 先读哪些证据

- `data_advisor_shop_product`：读取商品效果大盘和分层。
- `list_products_by_score`：获取质量分分布。
- `get_product_score_detail`：查看重点商品扣分原因。
- `product_query_information`：核实商品内容和交易模块。
- `icbu_ads_entity / icbu_ads_entity_detail`：商品涉及广告时只读查看计划关系。

## 判断方式

“印钞款/重点款”必须相对用户确认周期、店铺历史或平台返回行业基准判断；没有可比基准或订单金额时只描述现象，不使用固定询盘数门槛，也不判断 ROI。

校准规则：没有可迁移数字阈值时，只做定性分级，并写明需按行业、店铺历史或用户确认口径校准。

## 执行步骤

1. 先确定复盘周期、商品范围和是否包含广告商品。
2. 按效果、质量、内容、广告和风险建立商品分层。
3. 每个重点商品只给一个主处置方向：加码、优化、观察、清理或风险。
4. 输出商品经营复盘表、动作清单和人工确认项。
5. 不直接编辑、发布、删除、下架或改广告。

## 输出重点

商品分层、保留/加码/优化/淘汰建议。

## 常见误判

- 证据不足时给确定结论。
- 把建议动作写成已执行动作。
- 没有区分用户确认前后的边界。
- 把本子场景扩展成完整店铺报告或其他专门流程的交付物。
