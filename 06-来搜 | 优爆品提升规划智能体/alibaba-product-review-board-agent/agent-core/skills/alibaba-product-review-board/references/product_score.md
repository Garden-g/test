# 商品分巡检

## 触发词

商品分、质量分、扣分原因、商品质量巡检。

## 先读哪些证据

- `list_products_by_score`：按质量分区间拉低分、临界和高分商品。
- `get_product_score_detail`：查看扣分项和优化建议。
- `product_query_information`：核实标题、属性、图片、详情、交易和服务模块。
- `query_attribute_info` + `query_attribute_options_info`：确认类目属性定义和系统可选值。
- `list_risk_brand_name`：属性或标题涉及品牌词时复查风险。

## 判断方式

低分但无流量商品不一定优先；有流量低分优先。

校准规则：没有可迁移数字阈值时，只做定性分级，并写明需按行业、店铺历史或用户确认口径校准。

## 执行步骤

1. 先按用户指定分数段或默认巡检范围拉商品。
2. 质量分只作为线索，必须结合商品效果和风险判断优先级。
3. 把扣分项映射到可补属性、图片、详情、交易或服务模块。
4. 输出巡检清单、整改建议和复查指标。
5. 实际改商品字段必须转入人工确认后的编辑流程。

## 输出重点

商品分问题、优先级、修复动作。

## 常见误判

- 证据不足时给确定结论。
- 把建议动作写成已执行动作。
- 没有区分用户确认前后的边界。
- 把本子场景扩展成完整店铺报告或其他专门流程的交付物。
