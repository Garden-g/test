# 区域流量本地化

## 先读哪些证据

- 用户导出的国家流量、点击、询盘、成交和商品表现。
- 用户提供的页面截图、关键词、图片、MOQ、价格、物流、交期、认证和销售记录。
- `web_search` / `web_fetch` 返回的公开语言、使用场景、渠道、法规入口和买家顾虑。

## 判断方式

流量高但转化低不能直接归因于“本地化不好”。需要分别检查：

- 商品是否匹配该地区的使用场景与价格带。
- 语言、图片和信任证据是否能被目标客户理解。
- MOQ、交期、物流、付款、认证和售后是否形成阻力。
- 销售响应、资格判断和跟进是否承接了询盘。

## 执行步骤

1. 先确认国家、周期和异常指标；口径不一致时不做横向比较。
2. 把问题拆为商品、语言/素材、交易条件、交付、信任和销售承接。
3. 对每个可能原因列支持证据、反证、置信度和待验证动作。
4. 输出本地化素材/商品/销售动作和 30/60/90 天复查指标。
5. 页面发布、广告调整和发品只列待确认建议，不执行。

## 常见误判

- 只有流量差异就确定单一原因。
- 复制竞品文案、图片或商标。
- 把公开市场习惯写成每个买家的个人偏好。
- 把建议动作写成已完成的后台修改。
