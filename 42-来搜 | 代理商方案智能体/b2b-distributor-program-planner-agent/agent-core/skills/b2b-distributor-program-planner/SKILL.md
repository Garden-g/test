# 国际代理商方案

代理方案要先回答“什么伙伴能创造增量、企业能提供什么支持、用什么证据验证、何时升级或退出”，再谈独家和权益。

## 工具

- `ask_user`：确认产品/品牌、区域、渠道目标、毛利、价格体系、支持能力、独家态度、考核周期和审批人。
- `list`、`read`：读取现有渠道、价格、订单、客户、品牌、市场资料、权益表和协议草案。
- `web_search`、`web_fetch`：核对公开市场、渠道、候选伙伴、商标/法规入口和行业惯例线索。
- Browser：公开网页依赖脚本渲染时使用；不绕过付费或登录限制。
- `write`、`bash`、`process`、`present_files`：生成方案表格。

## 工作流

1. 定义渠道目标：覆盖区域、开发终端、库存与交付、售后、品牌建设、项目能力或回款，不用“多卖货”代替。
2. 建立代理画像：业务类型、渠道覆盖、团队、资金、库存、售后、市场投入、合规、利益冲突和真实合作意愿。
3. 设计准入—试运行—升级—独家—降级/退出路径。独家权必须建立在验证期、目标、投入、报告和退出条款上。
4. 设计等级权益：价格/返点、区域线索、样品、素材、培训、技术、市场共投、例会和管理层支持。每项写成本、条件、上限和审批。
5. 设计考核：采购与回款、渠道建设、库存、终端、品牌、售后、报告和合规；避免只按销售额。
6. 检查渠道冲突、最低广告价/转售限制、商标、反贿赂、制裁、数据、竞争法、税务和争议处理，由当地专业人员审核。
7. 为候选伙伴准备谈判问题、需核验证据、可给/换取、禁区和下一步。

知识材料提炼见 `references/method.md`；不得复制原协议正文作为最终合同。

## 表格交付

生成 `国际代理商方案_<区域>_<日期>.xlsx`：

| Sheet | 内容 |
|---|---|
| `渠道目标` | 区域、产品、客户、渠道任务、资源和阶段目标。 |
| `代理画像` | 必需条件、加分项、红线、证据和评分方法。 |
| `等级权益` | 等级、准入、权益、成本、条件、上限和审批。 |
| `考核机制` | 指标、口径、周期、证据、升级/降级/退出规则。 |
| `区域与冲突` | 区域、客户归属、线上线下、价格和冲突处理。 |
| `候选伙伴` | 公开证据、匹配、风险、待核验和下一动作。 |
| `谈判法务清单` | 商务问题、合同字段、专业审核和未决事项。 |

```bash
python3 scripts/build_workbook.py --input distributor.json \
  --output outputs/国际代理商方案_<区域>_<日期>.xlsx \
  --expected-sheets '渠道目标,代理画像,等级权益,考核机制,区域与冲突,候选伙伴,谈判法务清单'
```

## 边界

- 不编造候选代理的渠道、资金、客户、库存、合规或采购承诺。
- 不自动发出邀请、授予独家权、颁发授权书、改价、签约或收款。
- 不把知识库协议当可直接签署的法律文本；必须由目标市场律师审核。
- 权益和目标必须经财务、销售、供应链、品牌和管理层确认。
