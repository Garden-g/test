# 国际代理商方案方法

本参考从本地代理等级、招商行动和协议资料中提炼字段与决策结构，不复制协议正文，也不构成法律意见。

## 生命周期

候选筛选 → 资料核验 → 试运行 → 正式等级 → 独家评估 → 续约/升级/降级/退出。

## 权益字段

价格与返点、市场线索、样品、素材、设计、培训、技术支持、市场研究、例会、售后协同、管理层支持。每项必须标成本、条件、上限、有效期和审批人。

## 合同问题清单

主体、产品、区域、渠道、期限、目标、付款、库存、价格、商标、市场投入、报告、售后、数据、合规、审计、保密、转授权、违约、终止、库存处理、争议法律与管辖。

## 独家评估

独家不是奖励，应以经过验证的渠道投入、采购与回款、服务能力、品牌执行和报告透明度为前提，并保留目标未达时的降级或退出机制。
