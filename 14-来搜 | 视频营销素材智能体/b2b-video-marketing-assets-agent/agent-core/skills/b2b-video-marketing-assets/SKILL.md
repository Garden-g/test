# 外贸视频营销素材

视频先服务一个明确业务动作：让目标客户理解产品、愿意回复、预约会谈、访问展位、索取样品或继续推进。不要把镜头数量、特效或时长当成营销结果。

## 输入与定位

读取产品图/视频、品牌资料、卖点证据、客户画像、渠道要求和现有文案。用 `ask_user` 补齐会显著改变成片的内容：

- 目标受众与唯一行动目标；
- 使用渠道、比例、时长、语言和字幕；
- 产品、场景、人物、Logo、音乐与素材授权；
- 已证实的卖点、参数、认证、案例和禁止承诺；
- 需要纯策划、分镜 Prompt，还是确认后实际生成。

## 先做分镜

1. 用一句话定义“谁看、看懂什么、做什么”。
2. 建立事实账本，区分用户已证实、素材可见、公开来源、创意表达和待确认。
3. 按当前工具支持的单段时长拆成若干独立镜头。每个镜头写：目的、时长、画面、镜头运动、产品身份锚点、字幕/旁白、参考素材、转场、声音和事实状态。
4. 开头尽快呈现客户问题或使用场景，中段展示产品与证据，结尾只保留一个 CTA。
5. 无真实工厂、测试、客户或认证素材时，不得用生成画面冒充实拍证据；只能做明确标注的概念示意。

## 工具路线

- 有图片先用 `see_image` 检查产品、Logo、文字、比例和可复用范围。
- 需要补静态关键帧时，有参考图用 `image_edit`；无参考图且用户接受概念稿时才用 `image_generate`。
- 实际视频生成前检查当前 `video_generate_submit` schema，按其真实支持的图生视频或文生视频模式准备参数，不写死旧参数。
- 展示最终分镜、素材、时长、比例、版本数、预计调用次数和额度影响；取得用户对本次生成的明确确认后，逐镜头调用 `video_generate_submit`。
- 保存每个 `task_id`。只有任务已经完成并返回视频 URL 后，才调用一次 `video_generate_status` 获取调用记录；不要用它持续轮询。
- 当前工具不能拼接、配音、加字幕或导出指定格式时，交付分镜、素材与后期清单，不宣称已完成成片。

## 质量检查与交付

逐镜头检查产品形态、颜色、Logo、手部与人物、字幕拼写、镜头连续性、速度、裁切、闪烁、虚假结构和平台安全区。交付视频 URL 或文件、分镜表、使用渠道与比例、字幕/旁白、素材来源、事实状态、后期清单和未完成项。

## 边界

- 不自动上传、发布、投放、消耗广告预算或发送给客户。
- 不生成伪造的客户证言、工厂产线、检测过程、认证、销量、效果对比或新闻画面。
- 不使用未授权人物肖像、音乐、Logo、竞品素材或受保护视频片段。
- 任何外部发布、上传或付费生成都必须先确认具体版本、参数、调用次数和影响范围。
