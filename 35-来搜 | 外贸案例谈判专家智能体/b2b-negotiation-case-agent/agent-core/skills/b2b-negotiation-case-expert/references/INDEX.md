## 组合选择

- 先选 1 个主场景，再选最多 3 个次场景。
- “客户嫌贵并要求账期”读取比价压价 + 付款方式。
- “交期延迟导致客诉并拒付尾款”读取交期达不到 + 客诉售后 + 催尾款。
- “样品寄出后已读不回”读取样品 + 已读不回，必要时补跟进引导。
- “成本上涨，需要补差价且客户关系紧张”读取涨价补差价 + 客情挽回。

这些示例只用于选择资料，不代表对任何用户案例的预设结论。

## 使用边界

- 只吸收思路、逻辑框架、场景判断和方法论。
- 不引用、不复述、不近似改写文件中的具体案例和独特句子。
- 不输出知识库中的姓名、公司、产品、金额、日期、订单或联系方式。
- 原始文件位于 `source-documents/`，仅用于溯源或核对文本抽取；日常推理优先使用 `knowledge-base/` 的文本版本。
