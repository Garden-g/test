# 产品模特图

让人物帮助买家理解穿戴效果、握持方式、操作姿势或产品尺度，同时保持真实产品的结构、颜色、标签和使用逻辑。

## 执行

1. 确认产品、用途、目标市场、人物类型、场景、比例、输出数量，以及人物或品牌素材的使用授权。
2. 对产品图、人物图和参考图逐张使用 `see_image`，记录可见结构、尺寸线索、Logo、文字、水印、遮挡与画质。
3. 判断是否适合使用人物。服饰、鞋帽、可穿戴、手持工具和需要比例说明的产品优先；重型设备仅在表达操作位、安全距离或人机比例时使用。
4. 先给出姿势、镜头、场景、服装、光线、产品接触点和保持项。错误握持、错误穿戴、危险姿势或不真实比例必须在生成前纠正。
5. 用户确认生成后，用带产品参考图的 `image_edit`；用户指定人物时同时加入已授权人物参考。Prompt 明确只允许改变人物、背景、服装或构图，产品几何、颜色、材质、标签和比例必须保持。
6. 生成后用 `see_image` 检查产品保真、人体结构、接触关系、尺度、文字、品牌和使用安全；不合格时针对问题修复，不整套无目的重画。

## 边界

- 没有可用产品参考图时，只能交付方案，或经用户确认生成“概念示意”，不能声称是真实商品效果。
- 不生成未成年人敏感内容、危险使用方式、虚假代言、未经授权人物复刻或误导性前后对比。
- 不自动上传商品、替换店铺图片或发布社媒。
