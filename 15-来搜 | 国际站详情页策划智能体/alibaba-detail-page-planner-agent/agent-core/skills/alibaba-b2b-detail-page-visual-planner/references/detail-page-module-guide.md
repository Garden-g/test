# 详情页模块与行业追问指南

## 使用方法

先根据产品识别结果选择行业，再从本文件中挑选最相关的追问和模块。不要把全部问题一次性问给用户，也不要为了凑模块编造信息。

## 行业自适应追问

| 行业 | 优先确认的产品事实 | 可用 `ask_user` 选项示例 |
|---|---|---|
| 消费电子/电器 | 核心功能、供电/续航、接口/连接、APP、兼容性、环境适应性、安全认证 | 连接与接口 / 电池与供电 / 智能功能 / 防护与认证 |
| 工业机械/工具 | 用途、动力、处理能力、精度、尺寸、耗材、兼容性、安全、维护 | 效率与产能 / 精度与稳定 / 易维护 / 安全与适配 |
| 汽摩配件 | 适配车型、位置、材质、安装、测试、替代件号 | 车型适配 / 安装方式 / 材质耐用 / 测试与质保 |
| 包装容器 | 容量、材质、瓶口/封口、阻隔、印刷、表面工艺、套装 | Logo 印刷 / 容量形状 / 材质颜色 / 包装配件 |
| 美妆日化 | 成分、肤质/用途、容量、包装、法规、测试、使用方法 | 功效方向 / 适用人群 / 包装定制 / 合规与检测 |
| 食品饮料 | 配料、口味、规格、保质期、储存、过敏原、产地与认证 | 口味规格 / 包装形式 / 储存运输 / 认证检测 |
| 服装纺织 | 面料、克重、尺码、版型、颜色、工艺、洗护、季节 | 面料手感 / 尺码版型 / 颜色图案 / 标签包装 |
| 家具家居 | 尺寸、材质、承重、结构、安装、表面处理、使用空间 | 尺寸结构 / 材质颜色 / 安装收纳 / 场景搭配 |
| 建材/新能源 | 规格、材料、性能、安装、寿命、安全、认证、适用环境 | 性能参数 / 安装系统 / 环境适应 / 测试认证 |
| 医疗健康 | 用途、适用人群、风险等级、材料、使用限制、注册与检测 | 使用场景 / 产品材料 / 操作流程 / 注册与合规 |

如果产品涉及医疗、食品、儿童、安全、防护或强性能承诺，优先询问证据和限制，不先写营销话术。

## 模块库

以下 18 项是模块池，不代表要生成 18 张图。默认从中组合为 6-8 张独立竖图，任何情况下默认不得超过 8 张；只有用户明确要求更多图片时才增加。产品介绍通常占 2-4 张，其余相关模块合并呈现。

| 模块 | 解决的采购问题 | 推荐比例 | 核心素材 | 无证据时怎么处理 |
|---|---|---|---|---|
| 1. 产品定位主视觉 | 这是什么、适合谁、核心价值是什么 | 9:16 | 清晰主图、准确品名、目标买家 | 保留通用品名，价值点写待确认 |
| 2. 核心卖点总览 | 为什么值得继续看 | 9:16 | 3-4 个已验证卖点 | 只列采购关注维度，不写性能结论 |
| 3. 功能演示 | 主要功能怎么工作 | 9:16 | 操作步骤、功能素材、真实界面 | 改成待补演示脚本 |
| 4. 结构/材质细节 | 用什么做、关键部件在哪里 | 4:5 | 细节近景、结构图、BOM/材质证明 | 只标可见部件，不写材料等级 |
| 5. 参数规格 | 是否匹配采购要求 | 4:5 | 规格表、型号、测试条件 | 用字段模板，不填示例数字 |
| 6. 应用场景 | 在哪里、由谁使用 | 9:16 | 真实或授权场景图、适用边界 | 标为候选场景，不包装成客户案例 |
| 7. 产品集合 | 有哪些款式或型号可选 | 4:5 | 真实 SKU、颜色、尺寸、差异 | 没有 SKU 时不制造虚假系列 |
| 8. 定制服务 | 能定制什么、限制是什么 | 4:5 | Logo、尺寸/形状、材质/颜色、包装能力证明 | 全部写待确认，不默认支持 OEM/ODM |
| 9. OEM 工厂海报 | 谁在供货、服务能力如何 | 9:16 | 工厂实拍、服务范围、真实流程 | 不用通用工厂图证明身份 |
| 10. 生产流程 | 如何生产和控制一致性 | 9:16 | 真实工序、设备、质检节点 | 输出补拍清单，不编流程 |
| 11. 质检/检测 | 质量如何被验证 | 4:5 | 测试方法、设备、报告、适用型号 | 不做假仪器读数和假报告 |
| 12. 证书/合规 | 是否满足目标市场要求 | 4:5 | 有效证书、编号、机构、适用范围 | 无证据即不上线认证图标 |
| 13. 品牌合作/客户好评 | 是否有真实合作与口碑 | 4:5 | 授权 Logo、真实评价和可公开证据 | 改成“合作证据待补”，不造案例 |
| 14. 公司/团队/展会 | 供应商是否真实、是否能服务 | 9:16 | 公司、团队、展会真实照片 | 不用图库人物冒充团队 |
| 15. 合作流程 | 从询盘到交付如何推进 | 4:5 | 实际流程、节点、负责人或时效政策 | 只写通用步骤，时效待确认 |
| 16. 包装与物流 | 如何包装、装运、保护产品 | 9:16 | 包装层级、箱规、装柜/运输资料 | 不承诺未确认交期和物流时效 |
| 17. FAQ | 消除最后的采购疑虑 | 4:5 | 真实政策和高频问题 | 问题可以候选，答案必须待确认 |
| 18. 询盘 CTA | 买家下一步提供什么 | 9:16 | 询价字段、联系方式展示规则 | 使用平台询盘引导，不放私人联系方式 |

## 默认八图组合

| 图片 | 组合模块 | 建议比例 | 参考素材与生成方向 |
|---:|---|---|---|
| 1 | 产品定位主视觉 + 核心价值 | 9:16 | 主商品图放入 `image_edit.reference_images`，保持主体并建立详情页视觉基准。 |
| 2 | 核心功能 + 应用场景 | 9:16 | 继续复用主商品参考图，用 `image_edit` 改变场景和排版而不改产品。 |
| 3 | 结构材质 + 产品细节 + 参数 | 4:5 或 3:4 | 复用主商品参考图，使用 `image_edit` 做可见细节放大、参数卡和标注。 |
| 4 | 产品集合 + 定制服务 | 4:5 | 每个真实 SKU 图片都加入 `reference_images`；用 `image_edit` 做统一排版，不制造不存在的型号。 |
| 5 | OEM 工厂 + 生产流程 + 质检 | 9:16 | 工厂/流程真实照片加入 `reference_images`；用 `image_edit` 生成流程版式，不得只靠商品图虚构工厂。 |
| 6 | 品牌合作 + 客户好评 + 证书检测 | 4:5 | 使用授权 Logo、真实评价、证书/报告原件；以排版为主，不让 AI 伪造证据。 |
| 7 | 公司团队/展会 + 包装物流 | 9:16 | 使用真实团队、展会和包装物流照片；不得拿主商品图生成虚假人物或场地。 |
| 8 | 合作流程 + FAQ + 询盘 CTA | 4:5 或 9:16 | 可把已生成主视觉加入 `reference_images` 延续风格，流程和 FAQ 内容必须来自真实政策。 |

如果某产品需要 3-4 张产品详细介绍，可以减少或合并后半段信任模块，但默认总数仍不得超过 8 张。用户明确要求 9 张以上时，再按成交优先级拆分，不要自行扩张。

## 推荐叙事顺序

### 工业品/机械

产品定位 → 效率/性能 → 结构细节 → 参数 → 应用 → 型号集合 → 定制 → 工厂 → 生产质检 → 包装物流 → 合作流程 → FAQ/询盘。

### 消费电子/电器

产品定位 → 核心功能 → 操作/界面 → 结构与接口 → 参数兼容 → 应用 → 产品集合 → 定制 → 测试认证 → 工厂 → 包装 → FAQ/询盘。

### 包装、美妆、快消

产品定位 → 视觉卖点 → 材质/成分 → 使用体验 → 容量款式集合 → Logo/瓶型/标签/包装定制 → 质量检测 → OEM 工厂 → 品牌/客户证据 → 包装物流 → 合作流程 → FAQ/询盘。

### 服装、家居和生活方式产品

产品定位 → 面料/材质 → 细节工艺 → 尺寸 → 场景 → 款式集合 → 颜色/图案/包装定制 → 工厂与质检 → 公司团队 → 包装物流 → FAQ/询盘。

## 比例与版式选择

| 内容类型 | 首选比例 | 版式建议 |
|---|---|---|
| 主视觉、应用、工厂、团队、流程故事 | 9:16 | 单一大主体，标题和 2-3 个短卖点，留出移动端安全区 |
| 参数、细节、集合、定制、证书、FAQ | 4:5 | 上部主体，下部信息卡或分区表格 |
| 需要跨渠道复用的中型模块 | 3:4 | 兼顾画面和文字，避免过长滚动 |

不强制全部图片使用同一比例。应保持统一宽度、字体层级、颜色系统和图标语言，让不同高度的模块连续阅读时仍像同一套详情页。

## 信任证据最低要求

- 品牌合作：授权范围、可公开 Logo、合作对象和时间口径。
- 客户评价：真实来源、可公开程度、是否需要匿名、原始语言与翻译。
- 证书：证书名称、编号、机构、有效期、适用产品/型号。
- 检测报告：测试项目、条件、结果、实验室、报告编号、适用样品。
- 工厂与生产：真实地点/主体、照片授权、工序和设备归属。
- 包装物流：真实包装层级、箱规、运输方式和交付政策。

任何一项缺失时，详情图方案可以保留该模块，但必须标为 `待补证据`，不得生成貌似真实的示例内容。
