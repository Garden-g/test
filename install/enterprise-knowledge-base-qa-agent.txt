先用 curl 把上述不可变地址作为二进制文件下载到一个新的临时路径；Windows 使用 curl.exe。启用 HTTP 错误失败、重定向和有限次数重试。下载命令出现网络或 HTTP 错误时，应报告下载失败，不能误报为哈希错误。对下载到的 ZIP 本体计算 SHA-256 并精确比较；第一次不一致时删除本次临时 ZIP，再干净下载一次，第二次仍不一致就停止。

校验通过后，使用兼容 UTF-8 文件名的方式解压 ZIP，然后执行以下安装规则：

1. 读取 ~/.accio/state/current-space.json 确认当前 Accio Work 空间，不要根据目录修改时间猜测。
2. 校验 profile.jsonc、agent-core/、permissions/、agent-core/skills/skills.jsonc，以及 AGENTS.md、IDENTITY.md、SOUL.md、USER.md、MEMORY.md 五个核心提示词文件。
3. 智能体名称必须是“来搜 | 企业知识库问答智能体”，私有 Skill 必须且只能包含 enterprise-knowledge-base-qa，插件声明必须包含 knowledge-base-plugin。
4. 确认 profile.jsonc.id 在当前空间唯一；如有冲突，生成新的 MID-*，并保持目标目录名与 profile.jsonc.id 完全一致。
5. 确保 profile.jsonc.enabled 为 true。确认目标 agents/<agentId>/ 不存在，禁止覆盖；先复制到同级 .installing-<agentId>。
6. 检查私有 Skill 已写明强制使用 get_kb_file_contents 与 search_kb_file_contents、首轮 maxResults=20、证据不足时重检并最高提高到 50、每次列出实际引用文件、以及 Knowledge Base 与 Memory 冲突提醒规则。
7. 复核核心文件、私有 Skill、工具白名单、插件依赖和权限文件后，再把 .installing-<agentId> 原子改名为正式目录。
8. 私有 Skill 保留在 agent-core/skills/ 中，不要安装到全局 skills 目录。
9. 检查当前 Accio Work 空间是否真实安装并授权 knowledge-base-plugin；插件不可用时可以保留智能体，但必须明确说明知识库 Get/Search 尚不能运行，不得声称已完成 RAG 问答验收。
10. 安装成功后回报智能体名称、ID、最终路径、启用状态、工具白名单、插件依赖和私有 Skill，并提醒用户完整退出后重新打开 Accio Work。

本智能体只读取、检索和核对知识库，不负责创建、上传、编辑、删除知识库文件或修改权限。没有真实工具结果时，不得声称已经检索知识库。
