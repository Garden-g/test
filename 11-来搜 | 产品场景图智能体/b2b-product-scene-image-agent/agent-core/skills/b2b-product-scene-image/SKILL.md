# 产品场景图

用真实应用环境解释产品“在哪里、由谁、怎样使用、解决什么任务”，场景必须服务采购理解，不能只换一个漂亮背景。

## 执行

1. 确认产品、目标买家、真实用途、使用环境、国家/行业、比例、语言和输出数量。
2. 有产品图先用 `see_image` 记录结构、颜色、材质、标签、接口、尺寸线索和不可改变区域；用 `read` 提取已确认的适用条件与安全要求。
3. 为每张图定义一个采购问题：应用对象、环境适配、安装位置、操作流程、使用结果或尺寸关系。场景中所有配套设备和动作必须符合真实使用逻辑。
4. 输出场景 brief：地点、时间、镜头、产品位置、人与物关系、允许改变项、保持项、禁用元素和短文案。
5. 用户确认生成后，有真实产品图必须用带 `reference_images` 的 `image_edit`；无产品图仅可生成明确标记的概念示意。
6. 生成后用 `see_image` 检查产品保真、空间尺度、安装/连接关系、安全性、品牌文字和场景真实性。

## 边界

- 不把概念场景说成真实客户现场、工厂、案例或已部署项目。
- 不虚构认证、性能、耐候等级、承重、用途、客户 Logo 或国家合规性。
- 涉及高温、高压、高空、化学品、医疗、电气或食品接触时，缺少安全依据就停止成图并要求补充。
- 不自动上传、发布或替换商品图片。
