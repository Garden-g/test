# 产品卖点图

目标是让一张图只回答一个采购问题，并用真实产品特征和证据支撑，不用泛化口号填满画面。完整六图套图应使用专门的六图 Skill。

## 执行

1. 确认产品、目标买家、投放位置、语言、比例、主卖点和输出张数。用户未指定卖点时，从资料中推荐 3 个候选并说明依据。
2. 有图片先用 `see_image` 检查产品、可见文字、Logo、水印、比例和不可改变区域；用 `read` 提取用户已确认的参数、认证和案例。
3. 把卖点写成“产品特征/机制 → 买家问题 → 买家收益 → 证据 → 画面表达”。没有证据的内容列为待确认，不进入成图。
4. 输出构图 brief：英文短标题、产品主视觉、2-4 个证据模块、适用场景、底部采购信任项和安全留白。
5. 用户明确要求生成后，有真实产品图必须用带 `reference_images` 的 `image_edit`；没有参考图时只能生成明确标记的概念图。生成后用 `see_image` 检查产品保真、文字可读、信息层级和事实一致性。

## 生成确认与边界

调用图片生成前说明每张图的参考图、比例、允许改变项、保持项和调用次数。不要自动上传、替换商品图或发布页面。

禁止虚构参数、认证、产能、MOQ、客户 Logo、市场排名和效果数字；不要复制竞品图片或文案。图片中文字保持短句，生成文字错误时必须修正或如实标注，不能把乱码当成成品。
