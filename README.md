# 来搜 Accio Work 课程智能体套装

本套装包含课程实际使用的 47 个外贸业务智能体，覆盖市场与选品、国际站运营、营销素材、客户开发、销售转化和经营管理等场景，支持 Windows 和 macOS。

## 安装

1. 打开 [安装提示词](INSTALL_PROMPT.md)，复制对应系统的简短命令并发送给 Accio Work。
2. 等待 Accio Work 自动下载并完成安装。
3. 安装成功后，完整退出并重新打开 Accio Work，即可在智能体列表中使用。

安装器会把 47 个智能体一次性装入当前 Accio Work 个人或团队空间。所有名称统一为 `来搜 | {智能体名称}`，并使用同一份来搜 Logo；已有同来源旧版智能体会保留原 ID 原位升级，不会重复创建。

## v2.6.0 标题生成与长度校验修正

- `3-4 来搜 | 英文标题和五条卖点智能体` 已升级为关键词驱动的批量标题流程：先识别语种、产品方向、核心/次级市场和潜在 B2B 客户，再按关键词分组生成标题。
- 标题数量根据关键词数量动态增加，不再固定输出 4 条；所有原始关键词必须进入覆盖检查，存在未覆盖词时继续补充标题。
- 每条英文标题必须由内置脚本实际计算为 110–120 个字符，空格和标点计入；短于 110 或长于 120 字符时必须重写，不得作为正式结果交付。
- 900 词上新方案继续按 180 条链接、每条 5 词和 10 个工作表输出，并保留鑫梦达验收样本的表格结构与视觉契约；样本企业事实不得套用到其他企业。
- 从 v2.5.0 升级时，仅原位替换发生变化的 3-4 模板，保留原 Agent ID、用户画像、长期记忆和 v2.5.0 的透明底来搜 Logo；其余 46 个模板不变。
