# 店铺选品定位判断框架

## 证据顺序

1. 企业硬约束：能否生产、交付、认证、盈利和持续供货。
2. 店铺实证：现有商品、客户、国家、渠道、流量和询盘表现。
3. 行业证据：类目、国家、买家、趋势与机会工具返回。
4. 用户选择：主赛道、备选赛道和可接受的验证成本。

任何一层缺失都要在表格中说明，不用示例值补齐。

## 产品矩阵

- 引流品：容易被目标客户理解和搜索，用于获得有效访问。
- 主推品：最符合企业优势和当前客户需求，承担询盘与成交。
- 利润品：有差异化、服务或组合价值，承担利润。
- 形象品：展示研发、工艺、认证或完整解决方案，不以短期量为唯一目标。
- 试验品：证据尚不足，用最小 SKU、样品或小范围内容验证。

一个商品可以在特定阶段承担一个主要角色；不要为了填满矩阵强行分类。

## 停止条件

- 需要的认证或交付能力无法在验证期内补齐。
- 目标毛利在合理成本压力下仍不成立。
- 店铺与行业证据同时偏弱，且用户不愿承担验证成本。
- 产品涉及明确禁区、侵权、禁限售或供应不稳定。
