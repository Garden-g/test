# 国际站店铺装修策划

把“做一个 Banner”扩展为完整旺铺经营表达：买家先看懂卖什么、适合谁，再看到产品分类、差异证据、工厂能力、企业实力和明确询盘入口。

## 输入与诊断

用 `ask_user` 确认目标市场、核心买家、主营产品、主推系列、品牌定位、装修目标、现有页面和可用素材。用 `read` 读取公司、产品、认证、工厂、案例和品牌资料；有旧店截图、产品图或 Logo 时先用 `see_image`。用户要求当前市场或竞品对标时用 `web_search`、`web_fetch`，只学习结构和表达规律，不复制对方资产。

## 页面规划

1. 建立事实账本，区分已确认事实、图片可见、公开证据、待确认和禁止表达。
2. 诊断首页是否在首屏说明“卖什么、服务谁、核心差异、下一步做什么”。
3. 规划完整模块：首屏主张、主推品类、核心产品、应用行业、差异化证据、定制流程、工厂与质检、认证与实力、案例/常见问题、联系与询盘入口。
4. 同步规划产品分类与导航，避免按内部组织或模糊大类堆砌。
5. 为每个模块写目标、信息层级、短文案、事实依据、所需素材、桌面/移动端注意事项和验收标准。
6. 交付 `国际站店铺装修方案_<品牌>_<日期>.xlsx`，包含 `装修结论`、`页面架构`、`模块文案`、`产品分类`、`素材清单`、`实施验收`。

## 视觉素材

用户只要策划时不生图。用户明确要求制作某个 Banner、品类入口图、工厂模块图或实力模块图后，先展示输出数量、参考图、尺寸/比例、允许改变项和调用次数；有参考素材用带 `reference_images` 的 `image_edit`，无参考素材才用 `image_generate` 制作不冒充真实工厂或产品的概念背景。生成后用 `see_image` 验收。

## 边界

- 不编造工厂、认证、客户、产能、交期、专利、案例、员工或设备。
- 不把公开竞品素材复制进店铺，不使用未授权 Logo、人物或图片。
- 未取得用户对具体页面、模块和影响范围的确认，不调用任何创建、保存、上传、替换或发布店铺内容的工具。
- 当前交付是装修方案和素材，不声称已在目标店铺上线。
