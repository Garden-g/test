# 标题规则与关键词拆解参考

本 reference 用于生成最终标题批次前加载。它把“产品标题流程”和弹力帐篷/窗帘关键词表的可复用规则整理成可执行约束。

## 标题公式

优先使用下面 4 种结构，按产品资料灵活组合：

1. `营销词 + 关键属性 + 核心词 + for + 场景`
   - 示例：`Custom Waterproof Stretch Tent for Wedding Event Party Outdoor Use`
2. `关键属性 + 材质/结构 + 核心词 + for + B2B 场景`
   - 示例：`Four Way Elastic PU Coated Bedouin Stretch Tent for Commercial Event`
3. `数量/尺寸 + 功能属性 + 核心词 + for + 使用空间`
   - 示例：`Set of 2 Pieces Blackout Polyester Curtains for Hotel Living Room Windows`
4. `多语言同义词 + 核心词 + 属性 + for + 目标市场/场景`
   - 示例：`Custom Cortina Blackout Curtain Polyester Fabric for Hotel Window Decoration`

核心词要靠近标题中后段，介词 `for/with/in` 放在核心词后面连接场景或附加属性。一个标题里尽量只使用一个主要介词结构，避免变成长句堆词。

## 词类定义

### 核心词

产品本体词，必须每条标题都有。先确定单复数和常用变体：

- 弹力帐篷：`stretch tent`、`stretch tents`、`bedouin stretch tent`、`flexible tent`、`event tent`
- 遮光窗帘：`blackout curtain`、`blackout curtains`、`black out curtain`、`plain curtain`
- 坐垫套：`cushion cover`、`pillow case`、`pillowcase`、`throw pillow cover`
- 沙发套：`sofa cover`、`sofa slipcover`、`couch cover`
- 桌布：`table cloth`、`tablecloth`、`table cover`

如果核心词很多但词义接近，每条标题最多放 1-2 个，其他放到下一条标题轮换。不要把所有核心词都塞进同一条。

### 属性词

属性词优先级最高，必须真实：

- 功能：`waterproof`、`fireproof`、`flame retardant`、`UV resistant`、`soundproof`、`washable`
- 材质/结构：`polyester`、`knitted`、`PU coated`、`PVC coated`、`double layer`、`grommet`
- 尺寸/数量：`9m x 15m`、`52x84 inch`、`Set of 2 pieces`
- 克重/厚度：`320gsm`、`410gsm`、`700gsm`、`0.75mm`
- 颜色：`white`、`khaki`、`black`、`sand color`
- 定制：`custom size`、`custom color`、`logo printing`

属性词只能来自用户资料、商品详情、图片可见信息或明确关键词表。不能因为竞品有该属性就套到用户产品上。

### 场景词

场景词用于覆盖买家搜索意图：

- B2B 活动：`wedding`、`event`、`party`、`festival`、`commercial event`、`trade show`
- 空间：`hotel`、`restaurant`、`garden`、`beach`、`desert`、`patio`
- 采购对象：`supplier`、`manufacturer`、`factory`、`wholesale`

如果场景词和产品真实用途冲突，宁可不用。

### 营销词

营销词只能辅助，不要压过核心词和属性词：

- 可用：`custom`、`wholesale`、`factory price`、`supplier`、`manufacturer`、`high quality`
- 谨慎：`cheap`、`luxury`、`hot sale`，容易显得低质或泛滥
- 禁用或改写：`best`、`top`、`No.1`、`perfect`、`guaranteed`、`original`

### 多语言词

多语言词适合用来扩大区域搜索覆盖，但不要滥用：

- 西语/葡语常见：`cortina`
- 荷兰语：`gordijn`
- 德语：`Vorhang`
- 帐篷西语：`carpa`

同一标题最多放 1 个多语言词。标题主要语言仍然保持英文。

## 清洗规则

先删除高风险词，再删低价值词：

1. 删除品牌、公司、平台、店铺名。
2. 删除用户明确排除的属性词。
3. 删除不符合主图或真实产品的材质、工艺、尺寸、颜色。
4. 删除 C 端购买词和个人使用词，例如 `buy`、`DIY`、`home decor`、`kids bedroom`、`personal use`。
5. 删除绝对化和夸大词，例如 `best`、`top`、`No.1`、`perfect`。
6. 合并大小写、单复数和拼写变体；保留搜索量更高或更贴近 B2B 的写法。

## 标题差异化方法

生成多条标题时，不要只换词序。按以下维度轮换：

- 核心词轮换：`stretch tent` / `bedouin stretch tent` / `event tent`
- 属性组合轮换：防水 + PU 涂层、防火 + 700gsm、四向弹力 + 铝架
- 场景轮换：wedding、commercial event、restaurant、beach、trade show
- 采购意图轮换：custom、wholesale、factory、supplier
- 市场词轮换：South Africa、USA、Middle East 等，只有用户目标市场明确时使用

## 输出前检查清单

- 每条标题有核心词。
- 每条标题至少有 1 个真实属性词。
- 字符数不超过 128。
- 同一单词重复不超过 3 次。
- 不含品牌名、公司名、平台名。
- 不含用户排除词。
- 不含未确认的材质、克重、尺寸、颜色和认证。
- 标题表能解释每个词来自哪里。
